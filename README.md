# Implementa-o-Did-tica-de-Controle-de-Temperatura-Compara-o-entre-PID-Digital-e-On-Off
Bancada didática de controle de temperatura baseada em Arduino. Implementação de firmware para controle On-Off e PID (sintonia Ziegler-Nichols) aplicados a uma planta térmica de alumínio, com foco em ensino de engenharia de controle.
